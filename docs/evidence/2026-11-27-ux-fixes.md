## Limits

- Option group names ("Farbe", "Size") still come from the bundled interface vocabulary;
  only option values are merchant content.
- Translation jobs do not yet translate option value names; merchants name them in Studio.
- Storefront search over option names reads main products that store names without an
  index, so very large catalogues with names scan those rows.
- The legacy furniture fixture used by most suites keeps unnamed values on purpose
  (its immutability assertion in `checkout_handoff` expects the key).
