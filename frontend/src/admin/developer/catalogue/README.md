# admin/developer/catalogue

The rendered component catalogue of [`kit/ui`](../../../kit/ui/README.md), shown as the
Components tab of the developer workspace.

## Modules

- [`UICatalogue.tsx`](UICatalogue.tsx): Every kit/ui part with its states in the light and dark theme, and the catalogue index.
- [`catalogue-i18n.ts`](catalogue-i18n.ts): The page's sample labels in English, German, French and Spanish.
- [`ui-catalogue.css`](ui-catalogue.css): Page layout only, on design tokens.

## Verification

Run `npm test -- kit-ui` from `frontend/`.
