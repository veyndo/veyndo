# kit/api/generated

Generated contracts; do not edit. `routes.ts` comes from `scripts/api_catalogue.py`,
`operations/` from `scripts/testing/operation_contracts.py`. Both scripts fail with
`--check` when the committed files differ from the Rust sources.

## Modules

- `routes.ts`: Static route keys and the Rust file that declares each.
- [`operations/`](operations/README.md): Native operation inputs and declared outputs.
