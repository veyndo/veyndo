# Generated Veyndo clients

TypeScript (`typescript/`), Python (`python/`) and Rust (`rust/`) clients generated
from the component contracts in `../contracts/http`. Do not edit generated files;
run `python3 scripts/sdks/generate.py` from the repository root. Each folder has a
hand-written example (`examples/`) and smoke test.

Usage, coverage and limits: [docs/sdks.md](../docs/sdks.md).
